# Faro lab kit

Synthetic material for the course labs. Everything here is fictional: people, domains, files and figures.

| Folder | Contents |
| --- | --- |
| `en/`, `es/` | Faro case file and the worksheet templates for each lab, one copy per language |

## Worksheets

Each module's worksheets are added to `en/` and `es/` when the module is published, named `mNN-LNNx-<topic>.csv` (e.g. `m01-L01A-inventory.csv`).

Open a CSV with any spreadsheet app, fill it in and keep it as evidence; later modules build on it.

## Rules for new material

- Use only `.example` domains and invented names.
- Never include real credentials, personal data or real company names.
- Name files `mNN-LNNx-<topic>.<ext>` and add one copy per language.
