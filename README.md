# Ciberseguridad desde cero · Cybersecurity from scratch

An open, hands-on cybersecurity course in two separate editions, Spanish and English. Each module has a video class, an interactive guide with labs solved step by step, and references to CISSP domains and NIST publications. Learners practise with **Faro**, a fictional organization.

- Website: https://robertolopezhsec-cmd.github.io/ciberseguridad-desde-cero/
- Spanish edition: https://robertolopezhsec-cmd.github.io/ciberseguridad-desde-cero/es/ · English edition: https://robertolopezhsec-cmd.github.io/ciberseguridad-desde-cero/en/
- Lab worksheets and the Faro case file: [`lab-kit/faro/`](lab-kit/faro/)

New modules are added here as they are published.

## Report an error

Open an issue at https://github.com/robertolopezhsec-cmd/ciberseguridad-desde-cero/issues with the module number, the language and what looks wrong.
